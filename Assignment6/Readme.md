# Exception Handling Tasks

This folder contains five Jupyter notebooks and the sample text file used by Task4.

## Requirements

- Python 3
- Jupyter Notebook or JupyterLab

Install Jupyter if needed with `python -m pip install notebook`, then start it from this folder with `jupyter notebook` (or `jupyter lab`). Open a notebook and run its cells from top to bottom using **Run All**.

## Tasks

- `Task1.ipynb`: safe division with exception handlers, an `else` result, and a `finally` message.
- `Task2.ipynb`: bill calculator that skips invalid and negative prices while keeping a running total.
- `Task3.ipynb`: age validation; enter an integer when prompted. The caller catches validation and input errors.
- `Task4.ipynb`: file reading. Enter `data.txt` when prompted; keep the notebook's working directory alongside this file.
- `Task5.ipynb`: interactive shopping cart; enter prices and type `q` to finish.

`data.txt` is sample input for Task4. Task1, Task3, and Task5 prompt for input while running; Task2 uses the list defined in its notebook.
